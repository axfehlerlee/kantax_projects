# 스파르타클럽 커뮤니티 목업

스파르타클럽 커뮤니티의 **학습 질문** 화면을 HTML과 CSS로 재현한 과제입니다.
상단 내비게이션, 커뮤니티 메뉴, 검색 영역과 예시 질문 목록을 구성했습니다.

## 실행

[커뮤니티.html](./커뮤니티.html)을 브라우저에서 직접 열거나 VS Code Live Server로 실행합니다.
별도 패키지 설치 없이 열 수 있습니다. Pretendard 글꼴은 외부 CDN에서 불러오므로
해당 글꼴을 표시하려면 인터넷 연결이 필요합니다.

## 파일 구조

- [커뮤니티.html](./커뮤니티.html) — 화면 구조와 예시 질문
- [style.css](./style.css) — 레이아웃과 화면 스타일
- [images/](./images/) — 로고, 아이콘과 예시 이미지

## 구현 범위

상단의 외부 링크는 연결된 사이트를 새 탭에서 엽니다. 검색과 질문 작성은 화면만
구현했으며, 질문 목록은 HTML에 작성한 예시 데이터입니다.
