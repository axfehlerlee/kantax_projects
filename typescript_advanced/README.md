## 재실행

ZIP을 풀고 Node.js 환경에서 `npm ci`를 실행합니다. Jupyter가 설치된 환경에서 `npx tslab install --user`로 커널을 등록한 뒤, VS Code Jupyter에서 노트북을 열고 **TypeScript** 커널을 선택합니다.
