# kantax_projects
kant ax트랙 과제 제출 링크입니다.

## 프로젝트

| 폴더 | 내용 | 실행 방법 |
| --- | --- | --- |
| [python_final_project](./python_final_project/) | Python 도서 관리 시스템 | 폴더에서 `python main.py` 실행 |
| [final_assignment](./final_assignment/) | 머신러닝 최종 과제와 `diabetes.csv` | 해당 폴더에서 Jupyter Notebook 실행 |

Python 프로젝트의 실제 패키지 경로는 `library_system/`과 `utils/help.py`입니다.
머신러닝 노트북과 `diabetes.csv`는 같은 폴더에 둡니다. 필요한 패키지는 노트북 마지막 부분을 참고하세요.

### 이전 상태

두 프로젝트는 2026-09-06 기준 원본 파일 그대로 가져왔으며, 기존 커밋 이력은 포함하지 않습니다.
도서 등록·조회·검색·대여·반납·종료 흐름을 점검했습니다. 머신러닝 전체 실행은 수행하지 않았습니다.
현재 원본 노트북의 기대 CSV 체크섬이 동봉 CSV와 달라 해당 검증 셀에서 실행이 중단될 수 있습니다. 과제 데이터 확인 후 수정이 필요합니다.
